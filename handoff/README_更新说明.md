# LabScheduler v3.0（APP_VERSION 2026.10.08.10）

## 怎么用
- 直接用浏览器打开 `index.html`（单文件程序）。
- 原来的 `LabScheduler.exe` 是把 index.html 打包进去的本地服务端；它的 Go 源码不在这次的仓库里，所以这次**没有重新编译 exe**。把新的 index.html 交给原来的打包流程，或把服务端源码给我，就能重新出 exe。
- `assets/spirits/` 是精灵图片素材的热更新目录：每只精灵一个文件夹，里面有 `art_brief.md` 出图设定卡；按卡画好 `lv1.png ~ lv5.png` 放进同一个文件夹，后台点「扫描资源目录」即替换矢量图，缺图自动用矢量顶上。`KEY50.txt` 是重点 50 只名单。

## 这一版改了什么
- **365 只按 5 只示例的方向全部重做**：每只精灵一张元素表（本体 / 部件 A / 部件 B / 伙伴 / 核心徽记，3~5 个名称元素），三色取自元素，部件按本体实际外框挂。
- **LV1 保留蛋壳**：v2.5 差异化蛋形、壳纹、正面印记、破口都在，破口露出这只精灵的单一元素（= 伙伴元素）。
- LV2 元素组合（本体 + 部件 A）→ LV3 元素环境 / 伙伴（+ 部件 B + 伙伴队形）→ LV4 元素质变（按质变类型 × 3 种变体，伙伴元素一起质变，核心在身前成形）→ LV5 元素升华（领域 + 法相 + 核心徽记；领域里浮现的是这只精灵自己的元素）。
- **素材库扩展**：339 个元素图元；LV3 伙伴队形 7 种；LV4 质变变体 24 种（8 类 × 3）；LV5 法相 7 种；本体纹样 20 种。后台「美术资源」页底部新增「元素素材库」卡片，可看全部元素、每个元素被多少只用到、以及唯一性校验结果。
- **各不相同**：任意两只精灵的元素组合（部件 A + 部件 B + 伙伴 + 核心）都不重复；同类任意两只至少 4 项不同（本体 / 部件 / 伙伴 / 核心 / 纹样 / 队形 / 法相 / 质变 / 主色）。当前：重复 0 组，相似 0 对。
- **不拟人、不乱加**：有元素表的精灵不再套通用骨架、细棍手臂、翅膀、光环、皇冠、名称字元、系列点缀；部件不放在会被看成耳朵 / 翅膀 / 手臂 / 头发 / 皇冠 / 腿的位置；脚下不画光圈。名不副实的本体按元素改了（雷灵 → 闪电、萤火灵 → 小虫身 + 透明翅 + 尾光、龙舟灵 → 舟形、抽签灵 → 签筒）。
- **精灵画面不出现文字**（LV4 概念字、背景里的字全部去掉）。
