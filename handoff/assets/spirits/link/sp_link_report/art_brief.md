# 报告灵 · sp_link_report

## LV1

【LV1 报点灵】核心元素：报告、柱状图、书签、书页、奖章。单一元素：双层阶梯蛋，壳纹：冰裂纹，蛋壳正面印有「报告」剪影，顶部破口露出书页（单一元素）。
画风：赛尔号式粗描边赛璐璐：粗黑描边 3~5px，大色块，主色 ≤ 3 色（#3a5a8a / #e8b030 / #eef4fa），两阶硬阴影，无渐变，高饱和，头大身小、造型夸张；Q 版精灵，不拟人；透明背景，512×512 起；脚下不画光圈 / 地圈 / 法阵；翅膀 / 光环 / 皇冠不默认添加
禁止：拟人化、脚下光圈、脱离名称、与同类 / 跨类雷同、套模板

[LV1 Report Mote] Core elements: report, chart, bookmark, page, medal. a single element: Two-tier stepped egg, shell pattern: Crackle, a Report silhouette stamped on the front, the top crack reveals page (a single element).
Style: Seer-style thick-outline cel: bold black outlines 3–5px, big flat colour blocks, at most 3 main colours (#3a5a8a / #e8b030 / #eef4fa), two-step hard shadows, no gradients, saturated, big head and small body, exaggerated; chibi spirit, never humanoid; transparent background, 512×512 or larger; no ground ring, floor glow or magic circle; no wings, halo or crown unless they are core elements
Avoid: anything humanoid, ground rings, anything unrelated to the name, looking like other spirits, templated designs
