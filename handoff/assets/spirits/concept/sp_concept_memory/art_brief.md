# 记忆灵 · sp_concept_memory

## LV1

【LV1 记点灵】核心元素：记忆、记忆片、丝带、回忆泡、记忆锁。单一元素：上宽下尖蛋，壳纹：鳞片纹，蛋壳正面印有「记忆」剪影，左肩破口露出回忆泡（单一元素）。
画风：赛尔号式粗描边赛璐璐：粗黑描边 3~5px，大色块，主色 ≤ 3 色（#d88a5a / #5a8ad8 / #fff4ec），两阶硬阴影，无渐变，高饱和，头大身小、造型夸张；Q 版精灵，不拟人；透明背景，512×512 起；脚下不画光圈 / 地圈 / 法阵；翅膀 / 光环 / 皇冠不默认添加
禁止：拟人化、脚下光圈、脱离名称、与同类 / 跨类雷同、套模板

[LV1 Memory Mote] Core elements: memory, snapshot, ribbon, memory bubble, memory lock. a single element: Top-heavy pointed egg, shell pattern: Scales, a Memory silhouette stamped on the front, the left crack reveals memory bubble (a single element).
Style: Seer-style thick-outline cel: bold black outlines 3–5px, big flat colour blocks, at most 3 main colours (#d88a5a / #5a8ad8 / #fff4ec), two-step hard shadows, no gradients, saturated, big head and small body, exaggerated; chibi spirit, never humanoid; transparent background, 512×512 or larger; no ground ring, floor glow or magic circle; no wings, halo or crown unless they are core elements
Avoid: anything humanoid, ground rings, anything unrelated to the name, looking like other spirits, templated designs
