## LV1

【LV1 光点灵】核心元素：光显、显示屏、光斑、闪光、光核。单一元素：菱形蛋，壳纹：鳞片纹，蛋壳正面印有「光显」剪影，左肩破口露出闪光（单一元素）。
画风：赛尔号式粗描边赛璐璐：粗黑描边 3~5px，大色块，主色 ≤ 3 色（#5a3ad8 / #ffd84a / #f0eeff），两阶硬阴影，无渐变，高饱和，头大身小、造型夸张；Q 版精灵，不拟人；透明背景，512×512 起；脚下不画光圈 / 地圈 / 法阵；翅膀 / 光环 / 皇冠不默认添加
禁止：拟人化、脚下光圈、脱离名称、与同类 / 跨类雷同、套模板

[LV1 BOE Lumen Mote] Core elements: light display, display screen, light spots, sparkle, light core. a single element: Diamond egg, shell pattern: Scales, a BOE Lumen silhouette stamped on the front, the left crack reveals sparkle (a single element).
